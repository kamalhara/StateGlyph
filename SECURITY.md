# Security Policy

## Supported versions

Security fixes are provided for the latest published release. Before the first
release, the current `master` branch is the supported development version.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Instead,
[report it privately through GitHub Security Advisories](https://github.com/kamalhara/StateGlyph/security/advisories/new).

Include the affected package and version, reproduction steps, the expected
impact, and any suggested mitigation. You can expect an acknowledgement within
seven days. We will investigate, keep you informed of material progress, and
coordinate a fix and disclosure timeline with you when the report is confirmed.

Please avoid accessing or modifying data that is not your own while validating
a report.
