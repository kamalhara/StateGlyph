Add 24 state icons in seven categories: connectivity, security and privacy,
appearance, editing tools, files and folders, weather and time, and productivity.
New states include signal strength, theme preference, file access, daylight,
text alignment, task progress, and priority.

Animate both the outgoing and incoming glyph on every state change using
crossfade, scale, rotation, slide, or blur blending. Preserve one accessible SVG,
respect live reduced-motion preferences, cancel interrupted animations, and
support animated, duration, spinDuration, and transition props.

Include the same self-contained animation renderer in CLI-generated components,
automatically generate React subpath exports, and provide CSS timing presets.
